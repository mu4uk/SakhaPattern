# SakhaPattern

**Традиции в каждом пикселе** — цифровой конструктор якутских орнаментов для школьного научно-практического проекта (направление: цифровые технологии в креативной индустрии).

Это работающее веб-приложение: каталог мотивов, графический редактор, алгоритмическая генерация узоров, сохранение проектов, экспорт PNG/SVG и примерка узора на макеты продукции. Регистрация, сервер и платные сервисы не нужны.

Онлайн-версия: <https://mu4uk.github.io/SakhaPattern/>. Статическая сборка лежит в папке `docs` и публикуется через GitHub Pages.

---

## 1. Запуск

Требуется Node.js 18+ (проверено на Node.js 22).

```bash
cd SakhaPattern
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию <http://localhost:5173>).

### Демонстрация на другом ноутбуке

**Способ 1 — с установленным Node.js.** Скопируйте папку `SakhaPattern` на флешку или другой ноутбук, откройте в ней PowerShell и выполните:

```bash
npm install
npm run dev
```

Затем откройте <http://localhost:5173>. Если папка `node_modules` уже скопирована, `npm install` можно пропустить — тогда демонстрация работает даже без интернета.

**Способ 2 — без установки Node.js.** Скопируйте на флешку папку проекта и папку портативного Node.js `node-v22.23.5-win-x64` из `%LOCALAPPDATA%\Temp\opencode\node-portable\node-v22.23.5-win-x64`. Положите её рядом с `SakhaPattern` (или внутрь `SakhaPattern\node-portable`) и запустите `start-demo.bat`. Скрипт сам найдёт Node, установит зависимости при необходимости, поднимет сервер и откроет браузер.

**Способ 3 — собранная версия.** На этом компьютере выполните `npm run build`, скопируйте весь проект (включая `dist` и `node_modules`) и запустите `npm run preview`. Адрес: <http://localhost:4173>. Также можно зайти в папку `dist` через любой локальный HTTP-сервер; просто двойной клик по `dist/index.html` может не сработать из-за ограничений браузера к ES-модулям.

Важно: сохранённые работы лежат в LocalStorage конкретного браузера и **не переносятся** на другой ноутбук. При первом запуске там будут созданы 3 примерные работы. Свои результаты для показа лучше заранее скачать в PNG/SVG через кнопки экспорта.

Производственная сборка:

```bash
npm run build
npm run preview
```

Проверка типов:

```bash
npm run typecheck
```

## 2. Разделы приложения

| Раздел | Что делает |
| --- | --- |
| **Главная** | О проекте, возможности, метод «от традиции к дизайну», примеры применения |
| **Каталог орнаментов** | 31 учебный мотив (геометрия, симметрия, линии, композиция, растительные, зооморфные мотивы и кайма), поиск, фильтр по категориям, добавление на холст и в генератор |
| **Конструктор** | SVG-холст, сетка, масштаб, панорама, перемещение/поворот/масштаб элементов, слои, цвет, прозрачность, зеркалирование, генератор, сохранение, экспорт |
| **Применение** | 8 SVG-макетов: футболка, сумка, кружка, блокнот, открытка, плакат, логотип, магнит; смена цвета и масштаба узора |
| **Галерея работ** | Сохранённые проекты, предпросмотр, дата, открытие, удаление, экспорт PNG/SVG; 3 примерные работы при первом запуске |
| **Мир орнамента** | Образовательные материалы и интерактивный пример симметрии |

Навигация синхронизирована с хешем URL (`#editor`, `#catalog` и т. д.), поэтому кнопки «назад/вперёд» браузера работают.

## 3. Управление редактором

- Добавление элемента — клик по мотиву в библиотеке или кнопка в каталоге.
- Выбор — клик по элементу; список слоёв также позволяет выбрать элемент.
- Перемещение — перетаскивание мышью/пальцем.
- Изменение размера — красный маркер в правом нижнем углу выделения.
- Поворот — маркер над элементом.
- Масштаб холста — колесо мыши или кнопки внизу справа; панорама — зажатый пробел или перетаскивание пустой области.
- Клавиши: `Delete`/`Backspace` — удалить, `Ctrl/Cmd+D` — дублировать, стрелки — сдвинуть (со `Shift` — на 10 единиц), `Esc` — снять выделение.
- Автообновление генератора включено по умолчанию. После ручного редактирования холста оно отключается, чтобы не затирать правки; кнопка «Применить» возвращает сгенерированную композицию.

Экспорт: PNG с масштабом 1×–4× и выбором фона (прозрачный/белый/молочный/тёмный/как на холсте), а также векторный SVG.

## 4. Короткий сценарий показа (2–3 минуты)

1. **0:00–0:30** — «Каталог»: открыть мотив, показать описание формы и пометку об учебной реконструкции, нажать «Добавить на холст».
2. **0:30–1:10** — «Конструктор»: выбрать тип симметрии «Радиальная», 10 повторов, палитру «Земля саха», затем «Случайный вариант».
3. **1:10–1:45** — «Применение»: выбрать кружку или футболку, сменить цвет изделия и масштаб узора.
4. **1:45–2:20** — «Сохранить», скачать PNG и SVG, открыть работу в «Галерее».

## 6. Расширение данных

- **Новый мотив каталога**: добавьте объект в массив `ORNAMENTS` в `src/data/ornaments.ts`. Поле `interpretationNote` обязательно должно честно указывать характер описания.
- **Новая SVG-фигура**: добавьте запись в `SHAPES` в `src/lib/shapes.ts` и новый идентификатор в `ShapeId` (`src/types/index.ts`).
- **Новая палитра**: добавьте объект в `PALETTES` в `src/data/palettes.ts`.
- **Новый макет**: добавьте запись в `MOCKUPS` и SVG-разметку в `MockupArt` в `src/components/mocks/ProductMockup.tsx`.

## 7. Важное замечание об истории и символике

Описания мотивов носят характер **учебной визуальной интерпретации**: в приложении анализируются форма, геометрия, симметрия и возможности современного применения. Новые мотивы добавлены как учебные реконструкции по описаниям из научной литературы; это не копии конкретных музейных предметов. Проект **не приписывает** узорам неподтверждённые исторические сюжеты или символические значения и не заменяет работу с научными источниками.

## 8. Проверки

- `npm run typecheck` — проверка TypeScript.
- `npm run build` — производственная сборка Vite.
- Ручная проверка в браузере: навигация по всем разделам, добавление/редактирование элементов, генерация, сохранение, открытие и удаление проекта, экспорт PNG/SVG, макеты, адаптивность.

---

## 9. Известные ограничения

- Данные хранятся только в браузере конкретного устройства; при очистке LocalStorage проекты исчезнут (примерные работы будут созданы заново).
- Макеты продукции — схематичные SVG-иллюстрации, а не фотореалистичный рендер.
- SVG-фигуры являются авторскими учебными интерпретациями, а не точными копиями исторических орнаментов.
- HTML-редактор не поддерживает многослойную группировку, отмену действий (Undo/Redo) и работы с растровыми изображениями.
